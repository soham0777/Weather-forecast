## ✨ Features

- 🔎 Search weather for any city in the world
- 🌡️ Live conditions from the OpenWeatherMap API (metric units)
- 📱 Responsive layout that works on phone and desktop
- ⚡ No framework and no build step, just static files

## 🚀 Live Demo

👉 **https://soham0777.github.io/Weather-forecast/**

## 🛠️ Run it locally

```bash
git clone https://github.com/soham0777/Weather-forecast.git
cd Weather-forecast
# open index.html in your browser
```

To use your own API key, get a free one from [OpenWeatherMap](https://openweathermap.org/api) and set `apiKey` at the top of `script.js`.

## 📁 Structure

```
Weather-forecast/
├── index.html   # page layout
├── styles.css   # styling
└── script.js    # API call and rendering
```
